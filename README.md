# HSE_FQW

Прототип аналитической платформы с интеграцией Vector Database

## Описание проекта

Данный проект представляет собой прототип аналитической платформы с интеграцией векторного хранилища данных (Vector Database) для реализации семантического поиска по текстовым документам.

В рамках проекта реализованы:

- полнотекстовый поиск;
- векторный поиск на основе эмбеддингов;
- гибридный поиск;
- обработка и очистка текстовых данных;
- индексация документов в PostgreSQL и Qdrant;
- веб-интерфейс на Streamlit.

В качестве прикладного сценария используется поиск по нормативным и справочным материалам НИУ ВШЭ.

## Цель проекта

Целью проекта является исследование интеграции векторного хранилища данных (Vector Database) в аналитическую платформу для реализации семантического поиска по текстовым документам.

---

# Архитектура системы

Система состоит из нескольких основных компонентов:

## PostgreSQL

Используется для:

- хранения текстовых документов;
- хранения метаданных;
- реализации полнотекстового поиска.

## Qdrant

Используется для:

- хранения эмбеддингов документов;
- выполнения семантического поиска;
- поиска ближайших векторов.

## Sentence Transformers

Используется для генерации эмбеддингов текста.

Основная модель:

```text
sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
```

## Streamlit

Используется для реализации пользовательского веб-интерфейса.

# Установка и запуск

## 1. Клонирование репозитория

```bash
git clone https://github.com/GlebGerr/HSE_FQW.git
cd HSE_FQW
```

---

## 2. Создание виртуального окружения

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

---

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## 4. Запуск PostgreSQL и Qdrant

```bash
docker-compose up -d
```

---

# Подготовка данных

## 1. Сбор документов с сайта

```bash
python -m src.crawl_hse_site
```

Документы сохраняются в:

```text
data/hse_site/raw/
```

---

## 2. Подготовка корпуса документов

```bash
python -m src.prepare_russian_docs hse_site
```

Результат:

```text
data/hse_site/processed/russian_chunks.csv
```

---

## 3. Инициализация PostgreSQL

```bash
python -m src.init_postgres_ru hse_site
```

---

## 4. Построение эмбеддингов

```bash
python -m src.build_embeddings_ru hse_site
```

Результат:

```text
data/hse_site/processed/russian_chunks_embeddings.npy
```

---

## 5. Индексация в Qdrant

```bash
python -m src.index_qdrant_ru hse_site
```

---

# Запуск веб-интерфейса

```bash
streamlit run streamlit_app.py
```

После запуска интерфейс будет доступен по адресу:

```text
http://localhost:8501
```

# Поддерживаемые режимы поиска

## Полнотекстовый поиск

Использует механизмы PostgreSQL и поиск по ключевым словам.

## Векторный поиск

Использует эмбеддинги текста и поиск ближайших векторов в Qdrant.

## Гибридный поиск

Комбинирует полнотекстовый и семантический поиск.
